## 边界用例

- 色块跨越周边界（start 在上周 / due 在下周）→ 按周裁剪。
- 同项目两任务重叠 → 靠标题 + 泳道 + 描边区分。
- 已完成任务 → 不进周视图（现状）。
- 老库升级（含既有 `devtodo.db`）→ 数据不丢。
